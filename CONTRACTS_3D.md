# platesim 3-D: contracts

Adds to `CONTRACTS.md` (units, tags, test rules there still apply). Plan: the private file
`research/platesim_3d_plan.md` (not in this repository). This file is the interface between
parallel workers: code against it, do not change it. If it is wrong or incomplete, report that
in your final message.

## 1. Conventions

- Python 3.12. Internal units cm, s, mol, A, V, K. Names ending `_um`, `_mA_cm2`, `_ms`, `_h`,
  `_C` (degrees C when the name says temperature) carry other units.
- Arrays are C-ordered `[i, j, k]` = `(x, y, z)`. `z` points out of the wafer (up, away from Si).
  The wafer's top surface (field) before plating is at `z = 0`; features extend to `z = -depth`.
- Level set `psi`: signed distance in cm, **positive in electrolyte, negative in solid** (Si,
  seed, Cu). Same sign as the 2-D engine. The plating front is `psi = 0`.
- Cell-centred uniform grid, spacing `dx` (cm) equal in all directions. Cell `(i, j, k)` centre:
  `x = x0 + (i + 0.5) dx`, likewise `y`, `z` with origin `(x0, y0, z0)` at the low corner.
- Default float type for stored fields: `float32`. Sums, balances and time are `float64`.
- Boundary kinds per side, as strings: `"periodic"`, `"symmetry"`, `"halo"`, and for z only
  `"bottom"` (solid) and `"bulk"` (top plane). A boundary spec is a dict with keys
  `x_lo, x_hi, y_lo, y_hi, z_lo, z_hi`. Periodic must be set on both sides of an axis.
- No GPU framework import outside `platesim/tile3d/backend/*_gpu.py`. No import of GPL packages
  (ViennaPS, ViennaLS, klayout, pymeshlab, surfalize) at module import time anywhere.
- Tests: `tests/test_<package>_<topic>.py`, under 60 s per file, grids at most 48^3.
  Markers: `slow`, `gpu` (skip when no device).

## 3. `Grid3D` (`platesim/tile3d/grid.py`)

```python
@dataclass(frozen=True)
class Grid3D:
    shape: tuple[int, int, int]        # (nx, ny, nz)
    dx: float                          # cm
    origin: tuple[float, float, float] # cm, low corner (x0, y0, z0)
    bc: dict[str, str]                 # keys x_lo..z_hi, values as in section 1

    @classmethod
    def from_um(cls, size_um, dx_um, origin_um=(0, 0, 0), bc=None) -> "Grid3D": ...
    @property
    def periodic(self) -> tuple[bool, bool, bool]: ...   # per axis
    def centers(self) -> tuple[np.ndarray, np.ndarray, np.ndarray]: ...  # 1-D arrays, cm
    def meshgrid(self) -> tuple[np.ndarray, np.ndarray, np.ndarray]: ... # 3-D, indexing="ij"
    @property
    def cell_volume(self) -> float: ...                   # cm^3
    def to_dict(self) -> dict: ...                        # JSON-serialisable
    @classmethod
    def from_dict(cls, d) -> "Grid3D": ...
```

Default `bc`: periodic in x and y, `z_lo="bottom"`, `z_hi="bulk"`.
Level-set and operator functions do NOT take a `Grid3D`; they take arrays plus `dx` and
`periodic=(px, py, pz)` so they can be written and tested independently.

## 4. Level set (`platesim/tile3d/levelset3d.py`)

All functions take and return NumPy arrays of shape `(nx, ny, nz)`; `backend` is `"numpy"`,
`"numba"` or `"auto"` (numba when importable). Non-periodic sides use zero-gradient (edge) padding.

```python
def advect(psi, speed, dt, dx, periodic=(True, True, False), scheme="weno5",
           band_cells=None, backend="auto") -> np.ndarray
    # psi_t + speed |grad psi| = 0 ... with speed > 0 meaning the SOLID grows (front moves into
    # the electrolyte), i.e. psi decreases where speed > 0.  scheme: "weno5" (TVD-RK3) | "godunov1".
    # speed: scalar or array (cm/s).  band_cells: restrict to |psi| < band_cells*dx, or None.
def reinit(psi, dx, periodic=(True, True, False), narrow_cells=None) -> np.ndarray   # scikit-fmm
def extend(psi, field, dx, periodic=(True, True, False)) -> np.ndarray               # extension velocities
def grad_mag(psi, dx, periodic=...) -> np.ndarray
def curvature(psi, dx, periodic=...) -> np.ndarray          # div(grad psi/|grad psi|), 1/cm
def electrolyte_fraction(psi, dx) -> np.ndarray             # 0..1 per cell, smooth near the front
def solid_volume(psi, dx) -> float                          # cm^3, float64
def volume_correct(psi, target_solid_volume, dx, band_cells=8.0) -> np.ndarray
def label_voids(psi, bulk_mask, periodic=(False, False, False)) -> tuple[np.ndarray, int]   # electrolyte regions not connected to bulk_mask
```

The 2-D reference to port from is `platesim/feature/engine/levelset.py` and `ls_kernels.py`
(read-only). Sign convention of `advect` there: check it and match the statement above.

## 5. Operators (`platesim/tile3d/operators.py`, `solvers_ref.py`)

Scalar equation on active cells: `-div(k grad u) + r u = f`, 7-point finite volume.

```python
def face_coefficients(k_cell, periodic) -> tuple[np.ndarray, np.ndarray, np.ndarray]
    # harmonic mean of k on x, y, z faces; arrays shaped (nx+1,ny,nz), (nx,ny+1,nz), (nx,ny,nz+1);
    # boundary faces are 0 (no flux) unless periodic
def assemble(kx, ky, kz, dx, reaction=None, active=None,
             dirichlet=None, periodic=None) -> tuple[scipy.sparse.csr_matrix, np.ndarray]
    # pass periodic=(px, py, pz) explicitly; a Dirichlet outer face uses the adjacent cell's k
    # (kept by face_coefficients as array metadata, or give a non-zero outer face coefficient)
    # returns (A, b_bc) for unknowns ordered as u.ravel() (C order).  active: bool array, inactive
    # cells become identity rows with rhs 0.  dirichlet: optional dict
    # {"z_hi": value} (also x_lo.. keys) imposing a value on the outer face at half-cell distance.
def apply_matrix_free(u, kx, ky, kz, dx, reaction=None, active=None, dirichlet=None) -> np.ndarray
    # same operator without assembling; must equal A @ u.ravel() (+ nothing; b_bc is separate)
def solve_direct(A, b) -> np.ndarray          # scipy.sparse.linalg.spsolve
def solve_amg(A, b, tol=1e-10, x0=None) -> tuple[np.ndarray, dict]   # PyAMG-preconditioned CG, info dict
```

## 6. Result format (`platesim/tile3d/result.py`)

One run = one directory:

```
<run_dir>/
  manifest.json          # see section 7
  grid.json              # Grid3D.to_dict()
  frames/psi_0000.npz    # one file per saved time; keys: psi (float32, shape), t_s (float64 scalar)
  frames/psi_0001.npz
  fields/<name>_NNNN.npz # optional, same indexing: c_cu, phi, speed, ux, uy, uz
  static.npz             # psi_si: level set of the bare etched silicon+seed (float32), before plating
  series.json            # {"t_s": [...], "<scalar name>": [...]}, e.g. charge_C_cm2, solid_volume_cm3
```

```python
class TileResultWriter:
    def __init__(self, run_dir, grid: Grid3D, psi_si: np.ndarray, meta: dict | None = None): ...
    def add_frame(self, t_s: float, psi: np.ndarray, fields: dict[str, np.ndarray] | None = None,
                  scalars: dict[str, float] | None = None) -> int: ...   # returns frame index
    def close(self, manifest: dict | None = None) -> None: ...

class TileResult:
    def __init__(self, run_dir): ...
    grid: Grid3D
    times_s: np.ndarray
    psi_si: np.ndarray
    def psi(self, index: int = -1) -> np.ndarray: ...
    def field(self, name: str, index: int = -1) -> np.ndarray | None: ...
    series: dict
    manifest: dict
```

Frames are written as they are produced (never all held in memory). `np.savez_compressed`.

Synthetic fixtures (`tests/fixtures3d/make_fixtures.py`, functions returning a `TileResult` in
a temp dir, grid at most 48^3, dx 4 um): `box_step` (uniform growth of thickness t on a
rectangular trench: analytic psi), `half_filled_trench` (flat floor at half depth),
`via_with_void` (cylindrical via closed at the mouth with a sealed electrolyte pocket).
Each fixture also returns a dict of known answers (thicknesses, volumes, void volume).

## 7. Spec and manifest (`platesim/spec3d/`)

pydantic v2 models, `extra="forbid"`. Top-level `SampleSpec`:

```
layout:   {file: str | None, features: [Feature] | None, die_um: [w, h], pixel_um: float | None,
           layer_map: {name: layer}}
          Feature = {kind: "rect"|"rounded_rect"|"circle", x_um, y_um, w_um, h_um, r_um,
                     rotation_deg, layer, array: {nx, ny, pitch_x_um, pitch_y_um} | None}
etch:     {default: EtchLayer, layers: {name: EtchLayer}}
          EtchLayer = {depth_um, sidewall_deg (90 = vertical), bottom_radius_um,
                       depth_vs_width: [[width_um, depth_um], ...] | None, seed: "full"|"thinning"}
recipe:   {steps: [Step]}
          Step = {t_forward_ms, t_reverse_ms, t_off_ms, j_forward_mA_cm2, j_reverse_mA_cm2,
                  duration_h | charge_C_cm2}     # DC: t_reverse_ms = t_off_ms = 0
          derived (methods): j_net_mA_cm2, duty
bath:     {name: str = "EP-EC1-65L", cu_g_L, h2so4_g_L, cl_ppm, temperature_C}
setup:    {orientation: "vertical"|"face_up"|"face_down" = "vertical", up_edge: "+x"|"-x"|"+y"|"-y" = "+y",
           stir_shear_1_s: float | None, stir_angle_deg: float = 0, delta_um: float = 64,
           taped: bool, area_cm2: float}
numerics: {quality: "preview"|"standard"|"fine" = "standard", physics: "L1"|"L2"|"L3" = "L1",
           dx_um: float | None, device: "auto"|"cpu"|int = "auto", use_surrogate: bool = False}
```

Validation errors must name the field path, the value, the allowed range and a suggested fix.
`spec_hash(spec) -> str` is the SHA-256 of the canonical JSON (sorted keys, defaults filled).
`export_schema(path)` writes the JSON Schema.

Manifest (`Manifest` model):

```
{spec_hash, code_version, backend, device, dx_um, physics, created_utc,
 quantities: [{name, value, unit, uncertainty: float | None,
               flag: "calibrated"|"uncalibrated"|"extrapolated"|"interpolated"|"surrogate"|"preview",
               feature_id: str | None}],
 checks: [{name, value, limit, passed}],
 waveform_sensitivity: str,
 artifacts: [{kind: "png"|"gif"|"mp4"|"svg"|"vti"|"vtp"|"stl"|"gltf"|"csv"|"json"|"npz", path, title}],
 summary_text: str}
```

## 9. Analysis (`platesim/analysis3d/`) and rendering (`platesim/render3d/`)

Every function takes a `TileResult` (or `psi`, `psi_si`, `Grid3D`) and returns plain dicts and
arrays; writing files is optional through an `out_dir` argument and returns artifact entries.

```python

def thickness_map(psi, psi_si, grid) -> dict
def cross_section(psi, psi_si, grid, polyline_um, n_samples=None) -> dict
    # {"s_um": 1-D, "z_um": 1-D, "psi": 2-D (s, z), "psi_si": 2-D, "cu_outline": [polylines], "si_outline": [...]}

                                                       # overburden_um, fill_fraction vs time, closure_time_s
def void_report(psi, grid) -> dict                     # count, volumes_um3, centroids_um, seam flag

def export_surface(psi, grid, path, fmt="stl"|"vtp"|"gltf") -> dict
def export_volume(result, path) -> dict                # .vti with psi (and fields), one file per frame
```

Rendering uses PyVista off-screen (`pv.OFF_SCREEN = True`) and matplotlib (Agg) for 2-D plots.
Camera presets are fixed so repeated calls are comparable.

## 10a. Tile engine (`platesim/tile3d/fields.py`, `sim.py`, lead-owned)

```python
def top_height(psi, grid) -> np.ndarray            # cm, (nx, ny), first front crossing from the top
def run_tile(psi_si, grid, j_net_mA_cm2, duration_s, delta_um=64.0, params=None, T_C=22.0,
             run_dir=None, n_frames=10, dt_max=120.0, cfl=0.3, reinit_every=4, scheme="weno5",
             backend="auto", field_mask=None, progress=None, meta=None, volume_correct=False)
    # -> TileResult when run_dir is given, else dict(psi, series, summary, grid)
    # params: platesim.feature.engine.params.Params (default Params(suppressor=False)); physics L1 only.
    # The grid must reach z_plane = mean field height + delta_um (+ growth) + 2 cells, or it raises.
```

Performance note: `fields.py` rebuilds the LU/AMG setup on every inner iteration. Keep tiles at
most about 40 000 cells (e.g. 48 x 16 x 48) in tests and examples. Do not change `fields.py` or
`sim.py`; report problems instead (the multigrid backend will replace this).

## 10b. Sample pipeline (`platesim/sample3d/`)

```python
def plan_tile(spec: SampleSpec) -> dict
    # chooses the tile: window_um (xmin, ymin, xmax, ymax), dx_um, z_extent_um, periodic flags,
    # n_cells, est_seconds; never runs the solver.  Quality presets: preview dx 8, standard 4, fine 2
    # (numerics.dx_um overrides).  Refuses (ValueError with a fix) above 2e5 cells.
def build_geometry(spec, plan) -> tuple[np.ndarray, Grid3D]     # psi_si (cm) and its grid
def run_sample(spec: SampleSpec | dict | str, out_dir, progress=None) -> dict
    # validate -> plan -> geometry -> run_tile per recipe step (net current, step duration or charge)
    # -> analysis3d (height_map, feature_report, void_report, 1 default cross-section through the
    # first feature centre along x) -> render3d (surface iso PNG, height map PNG, cross-section PNG)
    # -> manifest.json (spec3d.Manifest) in out_dir; returns the manifest as a dict.
    # All quantities flagged "uncalibrated" (L1 has no additives); checks include faraday_error_rel
    # (limit 0.05) and cu_balance_rel (limit 0.01).
```

CLI: `python -m platesim.sample3d run <spec.json> --out <dir>` and `... plan <spec.json>`.

## 10c. Agent interface (`platesim/mcp3d/`)

MCP server (`mcp` Python SDK, FastMCP, stdio) exposing tools that wrap 10b and section 9:
`validate_spec`, `plan_run`, `run_sample` (returns run_id; runs in a background thread with
progress), `get_status`, `get_manifest`, `cross_section(run_id, polyline_um)`,
`height_map(run_id)`, `render(run_id, kind, camera)`. Runs live under one root directory given at
start-up. Every tool returns JSON with units in key names; errors return
`{"error": ..., "field": ..., "fix": ...}`.

## 10. Dependencies

`ref` (pyamg), `layout` (gdstk, ezdxf, shapely), `viz` (pyvista, matplotlib, imageio),

report it. While several workers share this checkout, do not let `uv` touch `uv.lock` or `.venv`:
run from the repository root with an isolated environment, for example
`uv run --no-project --python 3.12 --with numpy --with scipy --with scikit-fmm --with scikit-image --with numba --with pytest <more --with as needed> python -m pytest tests/<file> -q`
(set `PYTHONPATH=.` so `import platesim` works).
